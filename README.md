# Linux Labs

Hands-on Linux administration labs focused on building practical system administration skills.

This repository includes labs where I configure Linux systems, verify that they work, and troubleshoot problems when useful.

## Repository Structure

| Section | Focus |
| --- | --- |
| **01 — Shell & Scripting** | Shell environment, Bash scripting, loops, and conditionals |
| **02 — Users & Permissions** | Users, groups, sudo, ownership, and permissions |
| **03 — Software & Services** | RPM, DNF, repositories, systemd, and services |
| **04 — Processes, Logging & Scheduling** | Processes, logs, cron, systemd timers, and performance |
| **05 — Storage & Filesystems** | Partitions, filesystems, mounts, swap, and LVM |
| **06 — Networking & Remote Access** | Network configuration, SSH, file transfer, and network storage |
| **07 — Security** | SELinux and firewalld |
| **08 — Boot & Recovery** | Boot, troubleshooting, and system recovery |
| **09 — Containers** | Podman and basic container administration |

## Lab Approach

Labs generally include:

- Configuration
- Verification
- Troubleshooting when useful
- Key takeaways

The goal is to show what I configured, how I verified it, and how I fixed problems when something failed.

## Environment

- Red Hat Enterprise Linux
- Bash
- Linux command line
- Virtual machines
